## MCP & SKILLS

> MCP
>
> 工作机制：用户 > 输入 > 智能体 > LLM连接每个mcp server(需要知道每个mcp的name description parmas demo
>
> 本质：MCP本质是 做标准化，把用户输入转为 规范的提示词、过多且相似的MCP可能造成LLM注意力下降
>
> 适用：第三方接入平台统一调用接口方式（让其他智能体按规范调用）
>
> 
>
> SKILL（提示词的产品化）
>
> 工作机制：用户 > 输入 > 智能体(支持SKILLS的agent客户端-claude龙虾) > SKILLS的名称 和 描述 > 按需查找（渐进式披露） > 查找SKILL内部reference 并 调用 scripts脚本
>
> 本质：打包某个方向的能力
>
> 适用：批量重复性任务与标准范式
>
> ```
> 元数据：name description
> 核心目标：target - 描述要做的事情
> 执行流程：progress - 使用步骤 (先 再 再 最后)
> 执行约束: out - 注意事项
> ```
>
> 
>
> 两者对比
>
> - 首次链接时候SKILL只需元数据（name ）token   远小于  MCP的name description parmas demo
