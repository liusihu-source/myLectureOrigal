## 五、数组默认初始化值

> 以数组的动态初始化方式为例说明
>

- 整型数组元素的默认初始值
    - 0
- 浮点型数组元素的默认初始值
    - 0.0
- 字符数组元素的默认初始值
    - 0
- boolean数组元素的默认初始值
    - false
- 引用数据类型数组元素的默认初始值
    - null
