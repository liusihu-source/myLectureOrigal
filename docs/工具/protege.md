## 一、Active ontology

:bulb: 该界面显示当前激活本体的信息--本体注释和相关度量值。

:bulb: 右上角的:mag: 用于搜索任意内容（类、属性等），或按Ctrl + F

![image-20241008100717219](protege.assets/image-20241008100717219.png)

## 二、Entities

可以探索所有的类、属性 和 个体信息。

子选项卡可调整大小，同步更新对应内容，有跟踪链接

工具栏中的左右箭头按钮可以进行向后和向前导航， 类似 Web 浏览器
