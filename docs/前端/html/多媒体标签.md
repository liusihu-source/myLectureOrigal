# 多媒体标签

## 音频 

```
<audio src="AudioTest.ogg" 
   controls //表示是否启用自带控制组件
   autoplay //表示是否自动播放
   loop //是否默认循环播放
   muted //表示是否默认静音
   preload //表示是否默认缓冲
>
  <p>Your browser does not support the <code>audio</code> element.</p>
</audio>
```



## 视频

```
<video
  src="myVideo.mp4" 
  width="100px"
  height="100px"
  controls
  autoplay
  loop
  muted
  preload
  poster="poster.mp4" //表示视频封面 URL
>
  <p>Your browser does not support the <code>video</code> element.</p>
</video>
```

:bulb: [音视频比特率 => 更高的比特率 = 更少的压缩 = 更高的视频质量](https://developer.mozilla.org/zh-CN/docs/Web/API/MediaRecorder)



## 字幕标签 

```
<video controls poster="/images/sample.gif">
  <source src="sample.mp4" type="video/mp4" />
  <source src="sample.ogv" type="video/ogv" />
  <track kind="captions" src="sampleCaptions.vtt" srclang="en" />
  <track kind="descriptions" src="sampleDescriptions.vtt" srclang="en" />
  <track kind="chapters" src="sampleChapters.vtt" srclang="en" />
  <track default kind="subtitles" src="sampleSubtitles_en.vtt" srclang="en" />
</video>
```
