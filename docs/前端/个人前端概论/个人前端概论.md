# 个人前端概论

## 一、MDN

概念：开放协作平台，权威有官方示例

内容：HTML、CSS、JavaScript、浏览器API（`document`对象、`window`）、Web API（网络请求）

地址：https://developer.mozilla.org/zh-CN/



## 二、关系

1. 超文本标记语言（HTML）：
   - 骨架

2. 层叠样式表（CSS）：
   - 形象

3. 文档对象模型（DOM）：
   - **定义：**`document`对象 ，树状结构，每个树节点为一个DOM标签，通过JS交互
4. **浏览器对象模型（BOM）：**
   - **定义：** 浏览器本身的编程接口。如 `window`、`history`、`location` 和 `navigator`。通过JS交互
5. **JS API：**
   - 操控DOM、交互BOM
