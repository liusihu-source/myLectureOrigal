# 展开运算符

## 一、**语法**

函数参数：

```typescript
myFunction(...iterableObj);
```

字符串、数组：

```typescript
const iterableObj = [1,2,3,4]
let myStr = 'hello'
console.log(...myStr)  //h e l l o
console.log(...iterableObj) //1,2,3,4
```

构造字面量对象时，进行克隆或者属性拷贝（ECMAScript 2018 规范新增特性）：

```typescript
let objClone = { ...obj };
```



## 二、**使用案例**

```typescript
function myFunction(x, y, z) {}
var args = [0, 1, 2];
myFunction(...args);

```
