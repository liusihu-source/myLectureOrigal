# 箭头函数

> - 更简洁的[函数表达式](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/function)，没有自己的[`this`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/this)，[`arguments`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Functions/arguments)，[`super`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/super)或[`new.target`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/new.target)。
>- this指向 定义时外层作用域

## 一、语法

参数

```typescript
//基础语法
(param1, param2, …, paramN) => { statements }
(param1, param2, …, paramN) => expression
//相当于：(param1, param2, …, paramN) =>{ return expression; }

// 没有参数的函数应该写成一对圆括号。
() => { statements }

// 当只有一个参数时，圆括号是可选的：
singleParam => { statements }

//支持剩余参数 和 默认参数
(param1, param2,param3 = defaultValue1, ...rest) => { statements }

```

函数体

```typescript
// 函数体只有一个 `return` 语句，可省略 `return` 关键字和方法体的花括号
elements.map(element => element.length); // [8, 6, 7, 9]

//有花括号 内部必须添加return
```



## 二、this指向

> **普通函数的 `this`**：由调用方式决定
>
> **箭头函数的 `this`**：由定义时的词法作用域决定
>
> **构造函数中的 `this`**：指向新创建的对象
>
> **原型方法中的 `this`**：指向调用该方法的对象
>
> **回调函数中的 `this`**：通常是全局对象（除非用 `bind`、箭头函数等绑定）



### 2.1 普通函数、箭头函数与对象方法

```javascript
const obj = {
  name: 'obj',
  regularFunc: function() {
    console.log('1:', this.name);
    const innerFunc = function() {
      console.log('2:', this.name);
    };
    innerFunc();
    
    const arrowFunc = () => {
      console.log('3:', this.name);
    };
    arrowFunc();
  },
  arrowFunc: () => {
    console.log('4:', this.name);
  }
};

obj.regularFunc();
obj.arrowFunc();
```

```
1:'obj' //obj自身调用普通方法，this执行obj
2:'undefined' // 全局调用普通方法innerFunc，而全局没有name
3:'obj' // arrowFunc 的this取决于定义时的词法环境是regularFunc，而regularFunc的this指向是obj对象，所以obj对象的name为 'name'
4: undefined // arrowFunc 定义时的词法环境是obj对象，而obj对象在的环境this指向全局 全局没有声明name 所以是undefined
```





### 2.2 原型链、构造函数与箭头函数

```javascript
function Parent(name) {
  this.name = name;
  
  this.normalMethod = function() {
    console.log('Normal:', this.name);
  };
  
  this.arrowMethod = () => {
    console.log('Arrow:', this.name);
  };
}

Parent.prototype.sharedNormal = function() {
  console.log('Shared Normal:', this.name);
};

Parent.prototype.sharedArrow = () => {
  console.log('Shared Arrow:', this.name);
};

const child = new Parent('Alice');
const obj = { name: 'Bob' };

child.normalMethod();
child.normalMethod.call(obj);
child.arrowMethod();
child.arrowMethod.call(obj);
child.sharedNormal();
child.sharedNormal.call(obj);
child.sharedArrow();
child.sharedArrow.call(obj);
```

```
Normal: ‘Alice’ //指向实例对象的name
Normal: ‘Bob’ //call更改了绑定的this对象，所以是obj的实例name
Arrow: Alice // 箭头函数this定义时的词法环境是构造函数Parent， 而Parent的this指向实例时候的对象，所以是child对象，即name为Alice
Arrow: Alice // 这里更改this绑定无效，因为箭头函数的this在定义时候确定的
Shared Normal：Alice // 因为自身没有方法，从原型查找原型的this默认指向对象自身
Shared Normal：Bob // 同上，call更改this对象
Shared Arrow： undefined //定义时所在的作用域是全局（Parent.prototype.sharedArrow = ...在全局执行），所以定义时的 this是全局对象
Shared Arrow： undefined //同上，无法改变
```





### 2.3 setTimeout、事件监听与类方法

```javascript
class Counter {
  constructor() {
    this.count = 0;
    
    setTimeout(function() {
      console.log('Timeout 1:', this.count);
    }, 100);
    
    setTimeout(() => {
      console.log('Timeout 2:', this.count);
    }, 200);
    
    document.addEventListener('click', function() {
      console.log('Click 1:', this.count);
    });
    
    document.addEventListener('click', () => {
      console.log('Click 2:', this.count);
    });
  }
  
  increment() {
    this.count++;
    console.log('Increment:', this.count);
  }
  
  incrementArrow = () => {
    this.count++;
    console.log('IncrementArrow:', this.count);
  }
}

const counter = new Counter();
const incrementFunc = counter.increment;
const incrementArrowFunc = counter.incrementArrow;

counter.increment();
counter.incrementArrow();
incrementFunc();
incrementArrowFunc();
```

```
涉及到同步和伪异步，先同步，后异步
'Increment:', 1 // 类实例的count 为 0，同步方法++ 后，所以是1
'IncrementArrow:',  2 // 箭头函数的词法环境是class类，而类的this指向创建的对象 之前已经加过1了，所以再加是2
'Increment:'： undefined  // 直接复制方法体，incrementFunc() 相当于global.incrementFunc() 而全局的this 中count 为 undefined
'IncrementArrow:',  3 //同上由于定义时候决定了，所以this指向实例对象本身，但又加一 所以是3
Timeout 1：undefined //异步执行，但调用者是global 所以undefined
Timeout 2：3//异步执行，同上，因为定义，而且count没有在变化过，所以是3
```
