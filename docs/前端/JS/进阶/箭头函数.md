# 箭头函数

> - 更简洁的[函数表达式](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/function)，没有自己的[`this`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/this)，[`arguments`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Functions/arguments)，[`super`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/super)或[`new.target`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/new.target)。
>- this指向 定义时外层作用域

## 一、语法

参数

```typescript
//基础语法
(param1, param2, …, paramN) => { statements }
(param1, param2, …, paramN) => expression
//相当于：(param1, param2, …, paramN) =>{ return expression; }

// 没有参数的函数应该写成一对圆括号。
() => { statements }

// 当只有一个参数时，圆括号是可选的：
singleParam => { statements }

//支持剩余参数 和 默认参数
(param1, param2,param3 = defaultValue1, ...rest) => { statements }

```

函数体

```typescript
// 函数体只有一个 `return` 语句，可省略 `return` 关键字和方法体的花括号
elements.map(element => element.length); // [8, 6, 7, 9]

//有花括号 内部必须添加return
```



## 二、this指向

- 外层是全局范围，`this` 指向全局对象或 `undefined`（严格模式）
- 外层是普通函数，`this` 由调用方式决定
- 外层是构造函数或类方法，`this` 指向实例

```javascript
// 全局作用域
const arrowFn1 = () => console.log(this);
arrowFn1(); // window (或 undefined)

// 普通函数内部
function outer() {
  const arrowFn2 = () => console.log(this);
  arrowFn2();
}
outer.call({ x: 100 }); // { x: 100 }

// 构造函数中
function MyClass() {
  this.value = 200;
  this.arrowFn3 = () => console.log(this.value);
}
const obj = new MyClass();
obj.arrowFn3(); // 200

```
