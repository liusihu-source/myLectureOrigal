# 选择器

与各类DOM元素的匹配模式



## 通用选择器

```
* {
  color: green;
}
```



## 元素选择器

```
a {
  color: red;
}
```



## 选择器列表

```
h1,.special {
  color: blue;
}
```



## 类选择器

```
/* All elements with class="spacious" */
.spacious {
  margin: 2em;
}

/* All <li> elements with class="spacious" */
li.spacious {
  margin: 2em;
}
```



## id选择器

```
#demo {
  border: red 2px solid;
}
li#demo {
  border: red 2px solid;
}
```



## 属性选择器

略，用到查询

```
a[href^="#"] {
  background-color: gold;
}
```



## 选择器操作符

### 后代选择器

```
ul.my-things li {
  margin: 2em;
}
```

### 紧邻同级子代选择器

```
ul.my-things > li {
  margin: 2em;
}
```

### 相邻兄弟选择器

匹配元素为 p，且与 img 直接相邻的同级元素

```
img + p {
  font-weight: bold;
}
```

### 通用兄弟选择器

```
img ~ p {
  color: red;
}
```



## 结构伪类

### element:nth-child()

- element：nth-child(values)；
  - 匹配对应 element；
    - 匹配父元素正序第 value 个子元素；
    - 且该子元素为 element；
  - values；
    - even：偶数；
    - odd：奇数；
    - An + B：n 从 0 开始；

### element:nth-of-type()

- element：nth-of-type(values)；
  - 匹配对应 element;
    - 匹配父元素所有的 element;
    - 匹配这些 element 中的正序第 values 个元素;
  - values；
    - even：偶数；
    - odd：奇数；
    - An + B：n 从 0 开始;

## 优先级

| 选择器        | Identifiers | Classes | Elements | 特殊性 |
| ------------- | ----------- | ------- | -------- | ------ |
| h1            | 0           | 0       | 1        | 001    |
| p.class       | 0           | 1       | 0        | 010    |
| h1 + p[class] | 0           | 1       | 1        | 011    |
| #id           | 1           | 0       | 0        | 100    |

:bulb: 尽量不要使用id 和 !important

:bulb: 尽量使用样式叠加
