# background背景

## 背景颜色

```css
.exampletwo {
  background-color: rgb(153, 102, 153);
  /* 透明颜色 */
  background-color: transparent;
  color: rgb(255, 255, 204);
}
```



## 背景图片

```css
.catsandstars {
  background-image: url("startransparent.gif"), url("catfront.png");
  background-color: transparent;
}
```



## 图片排列

```css
.one {
  /* 不重复 */
  background-repeat: no-repeat;
  /* 尽可能多的重复, 裁剪 */
  background-repeat: repeat;
  /* 等效于 repeat no-repeat */
  background-repeat: repeat-x;
  /* 等效于 no-repeat repeat*/
  background-repeat: repeat-y;
}
```



## 图片大小

```css
.tiledBackground {
  background-image: url(https://www.mozilla.org/media/img/logos/firefox/logo-quantum.9c5e96634f92.png);
  background-size: 150px;
  background-size: auto; /* 保持纵横比 完全填充 */
  background-size: contain; /* 缩放背景图片以完全装入背景区，可能背景区部分空白 */
  background-size: cover;  /*缩放背景图片以完全覆盖背景区，可能背景图片部分看不见*/
}
```



## 图片视图位置

```css
p {
  background-image: url("starsolid.gif");
  background-attachment: fixed; /* 相对于浏览器页面固定不动 */
  background-attachment: local; /* 相对于元素内容固定不动 */
  background-attachment: scroll; /* 相对于父元素固定不动 */
}
```



# Figma到应用

- Figma-Hug：自适应填充，max-width: Hug对应值
- Figma-Fixed：固定值
- Figma-Fill：width: 100%; min-width: 210px; //**< 210px**保持 `210px` ，**≥ 210px** 拉伸至父容器 100% 宽度
