# 盒子模型

## box-sizing

| 属性             | `content-box` (标准盒模型) | `border-box`（怪异盒模型）       |
| :--------------- | :------------------------- | :------------------------------- |
| **width/height** | 仅内容区域                 | 内容 + padding + border          |
| **实际内容空间** | width - padding - border   | width 直接包含 padding 和 border |
| **布局直觉**     | 反直觉（需手动计算）       | 符合设计直觉                     |



## display属性

- outside；
- inside；
- outside + inside；

```
/* 外部属性 */
span {
  display: block;
}

/* 内部属性 */
span {
  display: flex;
}

/* 外部属性 + 内部属性 */
span {
  display: block flex;
}
```



## padding、margin、border、outline

|    使用场景     |                代码示例                |         效果         |
| :-------------: | :------------------------------------: | :------------------: |
|    水平居中     |           `margin: 0 auto;`            |     元素水平居中     |
|     右对齐      |          `margin-left: auto;`          |       元素靠右       |
| Flex 布局右对齐 | `display: flex;` + `margin-left: auto` | 在 flex 容器中右对齐 |
|  多列布局分隔   |             结合 flex 使用             |    创建灵活的间距    |



## aspect-ratio

```
/*设置盒子模型的固定长宽比*/
aspect-ratio: 1.6; width: 100%; 图片宽高比1.6
```



## 居中

flex

```css
.container {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

文本

```
.container {
  height: 100px;
  line-height: 100px;
  text-align: center;
}
```

绝对定位 + margin

```css
.father {
  width: 500px;
  height: 300px;
  border: 1px solid #0a3b98;
  position: relative;
}
.son {
  width: 100px;
  height: 40px;
  background: #f0a238;
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  margin: auto;
}
```

```css
.father {
    position: relative;
    width: 200px;
    height: 200px;
    background: skyblue;
}
.son {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%,-50%);
    width: 100px;
    height: 100px;
    background: red;
}
```
