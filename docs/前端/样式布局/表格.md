# table

## table-layout 属性

设置表格布局

### auto

- 根据表格内容自动调整表格宽度；

### fixed

- 根据表格第一行的宽度设置表格宽度；

```css
table {
  table-layout: fixed;
  width: 120px;
}
```



## border-collapse 属性

设置表格内部相邻单元格是否共享边框

### collapse

- 共享；

### separate

- 不共享；

```css
table {
  border-collapse: collapse;
}
```



## caption-side 属性

设置表格 caption 标签位置

### top

- 表格顶部；

### bottom

- 表格底部

```css
table {
  caption-side: top;
}
```



## 常用

- table-layout 属性值设置为 fixed；
- border-collapse 属性值设置为 collapse；
- 使用 text-align 属性；
- 使用斑马条纹；

```css
tbody tr:nth-child(odd) {
  background-color: #ff33cc;
}

tbody tr:nth-child(even) {
  background-color: #e495e4;
}

/* 若浏览器不支持 :nth-child, 设置表格背景颜色 */
table {
  background-color: #ff33cc;
}
```
