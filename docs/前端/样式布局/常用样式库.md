## 滚动条

```css
.s_noticeContent::-webkit-scrollbar{
  width: 8px;  /* 滚动条宽度 */
  background: transparent;  /* 背景透明 */
}
/* 滚动条滑块样式 */
.s_noticeContent::-webkit-scrollbar-thumb{
  background: #DDDCE5;  /* 半透明滑块 */
  border-radius: 4px;
}
/* 鼠标悬停时滑块更明显 */
.s_noticeContent::-webkit-scrollbar-thumb:hover{
  background: rgba(0, 0, 0, 0.5);
}
```



## 单（多）行显示

```css
/*单行*/
{
    display: inline-block; /* 或 block */
    max-width: 125px;
    white-space: nowrap; /* 禁止换行 */
    overflow: hidden;
    text-overflow: ellipsis;
}
```

```css
/*多行*/
.line-clamp-2 {
    display: -webkit-box;
    -webkit-box-orient: vertical;
    -webkit-line-clamp: 2;
    overflow: hidden;
    text-overflow: ellipsis;
}
```
