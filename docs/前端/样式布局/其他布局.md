# 其他布局

## 默认布局

- 块级：不同标签之间自动换行
- 内联：沿inline flow 排列，填满父标签空间换行



## float浮动

脱离常规文档流，但仍会影响行内/块元素布局，常用于文字环绕布局实现

```html
<img src="image.png" style="float: left; margin-right: 10px;">
<p>这里是文字，会环绕在图片周围...<p>
```



## BFC

概念：**BFC（Block Formatting Context，块级格式化上下文）** 是 Web 页面中 **一块独立的渲染区域**，它决定了其中的 **块级盒子（Block-level Box）如何布局，以及与其他盒子之间的关系和相互作用**



特点：

- BFC 内部元素垂直排列，水平方向拉伸至父容器宽度；
- BFC 内部元素的 margin 和 padding 不和外部元素共享边框；
- BFC 内部相邻块级元素垂直方向发生 margin collapse



实例：

| 方法                                                         | 说明                                    | 示例                               |
| :----------------------------------------------------------- | :-------------------------------------- | :--------------------------------- |
| **1. 根元素（`<html>`）**                                    | 页面根元素天然是 BFC                    | 无需设置                           |
| **2. `float`不为 `none`**                                    | 比如 `float: left;`或 `float: right;`   | `float: left;`                     |
| **3. `position`为 `absolute`或 `fixed`**                     | 绝对定位或固定定位                      | `position: absolute;`              |
| **4. `display`为以下之一：** • `inline-block` • `table-cell` • `table-caption` • `flex` • `inline-flex` • `grid` • `inline-grid` | 这些布局方式都会创建 BFC 或类似独立区域 | `display: flex;`、`display: grid;` |



## 三栏布局

绝对定位

```css
.outer {
  position: relative;
  height: 100px;
}

.left {
  position: absolute;
  width: 100px;
  height: 100px;
  background: tomato;
}

.right {
  position: absolute;
  top: 0;
  right: 0;
  width: 200px;
  height: 100px;
  background: gold;
}

.center {
  margin-left: 100px;
  margin-right: 200px;
  height: 100px;
  background: lightgreen;
}
```

flex

```css
.outer {
  display: flex;
  height: 100px;
}

.left {
  width: 100px;
  background: tomato;
}

.right {
  width: 100px;
  background: gold;
}

.center {
  flex: 1;
  background: lightgreen;
}
```

## 对角线布局

```css
.flex-container {
  width: 300px;
  height: 300px;
  overflow: hidden;
  display: flex;
  background-color: gainsboro;
  justify-content: space-between;
}

.flex-container > div {
  width: 33%;
  height: 33%;
  background: pink;
}

.item-2 {
  align-self: center;
}

.item-3 {
  align-self: flex-end;
}
```



## 隐藏元素

|         方法         | 占据空间 | 响应事件 | 支持动画 | 可获取尺寸 | SEO影响 |      适用场景      |
| :------------------: | :------: | :------: | :------: | :--------: | :-----: | :----------------: |
|   `display: none`    |    ❌     |    ❌     |    ❌     |     ❌      |   大    |    完全移除元素    |
| `visibility: hidden` |    ✔️     |    ❌     |    ✔️     |     ✔️      |   中    |   保留空间的隐藏   |
|     `opacity: 0`     |    ✔️     |    ✔️     |    ✔️     |     ✔️      |   小    | 视觉隐藏但保留交互 |
| `position: absolute` |    ❌     |    ❌     |    ❌     |     ✔️      |   无    |    可访问性优化    |
|  `width/height: 0`   |    ❌     |    ❌     |    ❌     |     ❌      |   中    |    简单元素隐藏    |
