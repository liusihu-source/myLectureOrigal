# 文本字体

## 文本水平布局 

```css
.example {
  text-align: start;
  text-align: end;
  text-align: left;
  text-align: right;
  text-align: center;
  text-align: justify;
}
```



## 行间距

```css
div {
  /* 默认值 */
  line-height: normal;
  line-height: 1.2;
}
```



## 字间距

```css
.normal {
  /* 默认值 */
  letter-spacing: normal;
  letter-spacing: 1.2;
}
```



## 词间距

```
#mozdiv1 {
  /* 默认值 */
  word-spacing: normal;
  word-spacing: 1.2;
}
```



## 单行省略文本

```
display: inline-block; /* 或 block */
max-width: 125px;
overflow: hidden;
text-overflow: ellipsis;
white-space: nowrap; /* 禁止换行 */
```



## 多行省略文本

```css
.line-clamp-2 {
    display: -webkit-box;
    -webkit-box-orient: vertical;
    -webkit-line-clamp: 2;
    overflow: hidden;
    text-overflow: ellipsis;
}
```



## 字体类型

```css
.serif {
  font-family: Times, "Times New Roman", Georgia, serif;
}
/*读取第一个，若不存在，则读取第二个*/
```



## 字体颜色

```css
.serif {
  color: red.;
}
```



## 字体样式

```css
/* 正常 */
.normal {
  font-style: normal;
}
/* 斜体 */
.italic {
  font-style: italic;
}
/* 人为倾斜 */
.oblique {
  font-style: oblique;
}
```



## 字体粗细

- normal：对应 400；
- bold：对应 700；

```css
p {
  font-weight: bold;
}

div {
  font-weight: 600;
}

span {
  font-weight: lighter;
}
```



## 字体引入

```css
@font-face {
  font-family: "Open Sans";
  src: url("/fonts/OpenSans-Regular-webfont.woff2") format("woff2"), url("/fonts/OpenSans-Regular-webfont.woff")
      format("woff");
  font-weight: bold;
  font-style: normal;
}

@font-face{font-family:'DingTalk JinBuTi';src:url('../fonts/DingTalk JinBuTi.ttf');}
@font-face{font-family:'D-DIN';src:url('../fonts/D-DIN.otf');}
```
