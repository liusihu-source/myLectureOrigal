# 单位类型变量

## 相对单位

vh 百分比 rem em



## 绝对单位

px



## 像素

### css像素 - 逻辑像素

- css 的长度单位；
- px

### 设备像素 - 物理像素

- device pixel；
- 设备的物理像素；
- 单位为 pt

### 设备像素比 - dpr

- 1个css像素由多少个物理像素渲染
- 设备像素与设备像素的比值
- 若 dpr 为 2，2 * 2 个设备像素对应一个 css 像素，以此类推

```css
/* 普通 DPR = 1 的设备 */
.bg-image {
  background-image: url('image@1x.jpg');
}

/* DPR >= 2 的设备，如 Retina 屏 */
@media (-webkit-min-device-pixel-ratio: 2), (min-resolution: 192dpi) {
  .bg-image {
    background-image: url('image@2x.jpg');
    background-size: 100px 100px; /* 假设 @2x 图片是两倍大小，需等比缩小显示区域 */
  }
}

```

```javascript

// 获取设备像素比
const dpr = window.devicePixelRatio || 1;
console.log('当前设备的 DPR:', dpr);

// 根据 DPR 动态设置图片地址（假设 baseName 是图片名称）
function getHighDPIImage(baseName, width, height) {
  if (dpr >= 3) {
    return `${baseName}@3x.jpg`; // 3倍图
  } else if (dpr >= 2) {
    return `${baseName}@2x.jpg`; // 2倍图
  } else {
    return `${baseName}@1x.jpg`; // 普通图
  }
}
```



组件中模块化引入相对单位

```javascript
;(function (doc, win) {
  const docEl = doc.querySelector('html')
  const recalc = function () {
    const clientWidth = docEl.clientWidth
    docEl.style.fontSize = 100 * (clientWidth / 1920) + 'px'
  }
  win.addEventListener('resize', recalc, false)
  doc.addEventListener('load', recalc, false)
  recalc()
})(document, window)

```
