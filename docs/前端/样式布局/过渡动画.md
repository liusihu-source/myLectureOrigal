# 过渡动画



## 过渡

- transition

```css
/*如原先样式 和 hover更换*/
transition: opacity 0.3s, visibility 0.3s;
```



## 动画

- animation

```css
/*侧边栏*/
<div class="box"></div>
.box {
  background-color: rebeccapurple;
  border-radius: 10px;
  width: 100px;
  height: 100px;
}

.box:hover {
  animation-name: rotate;
  animation-duration: 0.7s;
}

@keyframes rotate {
  0% {
    transform: rotate(0);
  }
  100% {
    transform: rotate(360deg);
  }
}

```
