# Vue指令

> v-xx开头都是指令
>
> - `v-xxx="value"` 值传给指令
> - `v-xxx:arg="value"` 值传给指令参数
> - `v-xxx:arg.modifier="value"` 使用指令及修饰符



## v-for

```javascript
<template>
  <div>
    <ul>
      <li v-for="item in items" :key="item.id">
        {{ item.name }}
      </li>
    </ul>
  </div>
</template>

<script>
export default {
  data() {
    return {
      items: [
        { id: 1, name: "Apple" },
        { id: 2, name: "Banana" },
        { id: 3, name: "Cherry" },
      ],
    };
  },
};
</script>

```

:bulb: diff优化策略之一，方便标识并快速定位vnode 的id，动态修改



## v-if 与 v-show 区别

- v-show适合频繁切换显示/隐藏状态的场景。只涉及CSS的display，性能开销较小。
  - 会触发CSS过渡效果（transition）
- v-if适合用不频繁，因为它每次重新渲染时都会进行完整的DOM操作，性能开销较大。



## v-if 与 v-for

vue2版本，v-for优先级高于v-if

vue3版本，v-if优先级高于v-for

同时使用，可能导致调试 和 运行理解困难，推荐外层v-if 内层v-for防止不必要的遍历



## v-html

原生指令，可用于插入html内容

```vue
<template>
  <div v-html="htmlContent"></div>
</template>

<script>
export default {
  data() {
    return {
      htmlContent: '<!-- This is an HTML comment -->'
    };
  }
};
</script>

```



## v-cloak 和 v-pre

v-cloak，在Vue实例`完成编译 和 渲染前隐藏未编译的模板内容`

:bulb: 适合应用启动阶段，确保用户看不到闪烁的内容

```vue

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Vue v-cloak Example</title>
  <style>
    [v-cloak] {
      display: none;
    }
  </style>

<div v-cloak>
  {{ message }}
</div>

```



v-pre，`跳过该元素 及 子元素的编译过程，直接输出原始内容`

:bulb: 适合临时关闭某些节点的Vue编译功能

```html
<div v-pre>
  {{ message }}
</div>

```

上述代码会直接显示 `{{ message }}`，而不是渲染变量 `message` 的值。



## V-bind 与 V-model

| 特性     | v-model                                                      | v-bind                  |
| -------- | ------------------------------------------------------------ | ----------------------- |
| 绑定方向 | 双向绑定（`prop` 和 `event` 同时绑定）单向绑定（从数据到视图） |                         |
| 语法糖   | `v-bind` 和 `v-on` 的组合                                    | 单纯的属性绑定语法      |
| 适用场景 | 表单控件、自定义组件的双向数据同步                           | 动态绑定 DOM 属性       |
| 缩写形式 | 无缩写                                                       | `:` 是 `v-bind:` 的缩写 |

表单控件

```vue
//父组件
<Collapse
  v-model:show="showCard"
  v-model:baseOptions="baseOptions"
  @startCreating="startCreating"
  ref="configCollapseRef"
></Collapse>

//子组件
const models = defineModel({
  baseOptions: {  
    type: Object,
    default: () => ({
      configDataProcess: 'append',
      model: 'Deepseek-R1',
      userInput: '',
      isDeepSeekDeep: false
    })
  },
  show: {
    type: Boolean,
    default: true
  }
})

const { baseOptions, show } = models
```

## 自定义指令

- 全局注册 Vue.directive('xxx',{}) 
- 局部注册 组件内部设置directive，组件中就可使用该指令

- 应用场景 图片懒加载 和 页面水印



## 常见修饰符

- 表单修饰符
  - lazy 光标离开标签赋值 `<input type="text" v-model.lazy="value">` 
  - trim 过滤空格 `<input type="text" v-model.trim="value">`
  - number 转数值 `<input v-model.number="age" type="number">`
- 事件修饰符
  - stop/.self   阻止事件冒泡() `<button @click.stop="shout(1)">ok</button>`
  - prevent 阻止事件默认行为 `<form v-on:submit.prevent="onSubmit"></form>`
  - once 只触发一次 `<button @click.once="shout(1)">ok</button>`
  - native 监听原生事件
- 鼠标按键修饰符
  - left right middle 左键、右键 中键
  -  `<button @click.left="shout(1)">ok</button>`
