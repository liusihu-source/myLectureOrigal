# 移动端测试

- 打开 PC端 fidder  并保持同一局域网
- 先保证有网 => 再切换为手动 改ip  =>  软件打开（可选，如果需要在软件中打开）
  - 如没有手机 可用雷电模拟器

```json
//项目依赖
"vconsole": "^3.15.1"
```

```javascript
import { createApp } from 'vue'
import App from './App.vue'
import router from './router/index.js'
import '@/assets/js/ratio.js'
import useVant from './assets/js/vant.js'
import directives from './directives/index.js'
import global from './assets/global'
import VConsole from 'vconsole'

const isDev = process.env.NODE_ENV === 'development'
if (isDev) {
  new VConsole()
}

const app = createApp(App)

directives(app)
useVant(app)

app.use(router)
app.use(global)
app.mount('#app')

```
