- ...



## 文件引用

#### 紧耦合文件用相对路径

```js
//方便整个文件件的挪移
// 正确用法
import styles from './index.module.scss'
// 错误用法
import styles from 'src/pages/seller/index.module.scss'
```



#### 公共文件用绝对路径

```javascript
// 因为是公共使用，所以放src下,替换时候全局替换 alt + f
// 正确用法
import Input from 'src/components/input'
// 错误用法
import Input from '../../components/input'
```
