# 构建工具

## 一、Webpack

### 启动过程

1. 命令解析
   1. 查找json文件scripts定义的serve命令，通常对应vue-cli-service serve
2. 启动开发服务器
   1. webpack创建内存文件系统
   2. 启动Koa开发服务器
   3. 建立WebSocket 用于热更新
3. 依赖图构建
   1. 分析入口文件main.js 递归所有Import / require依赖
   2. 创建完整模块依赖图
4. 编译转换
   1. .vue - > vue-loader
   2. .js -> babel-loader
   3. .scss -> sass-loader + css-loader
5. 打包输出到内存文件系统
6. 开发服务器返回index.html 并在浏览器渲染 

### 常用配置

#### entry

作用：确定依赖图入口文件

```javascript
entry: './src/main.js'
```



#### output

作用：控制打包输出位置和文件名

```javascript
output: {
  path: path.resolve(__dirname, 'dist'), // 输出目录
  filename: '[name].[contenthash].js',   // 文件名模板
  publicPath: '/assets/',                // CDN路径或公共路径
  clean: true                            // 构建前清空目录
}
```



#### module.rules

作用：模块处理，定义不同类型文件的处理规则

```javascript
module: {
  rules: [
    {
      test: /\.js$/,                   // 匹配文件
      exclude: /node_modules/,         // 排除目录
      use: ['babel-loader']            // 使用loader
    },
    {
      test: /\.scss$/,
      use: [
        'style-loader',  // 注入<style>标签
        'css-loader',    // 解析@import/url()
        'sass-loader'    // 编译SASS->CSS
      ]
    }
  ]
}
```



#### plugins

作用：扩展webpack功能

```javascript
plugins: [
  // 自动生成HTML文件
  new HtmlWebpackPlugin({
    template: './public/index.html'
  }),
  
  // 定义全局变量
  new webpack.DefinePlugin({
    'process.env.NODE_ENV': JSON.stringify('production')
  }),
  
  // 提取CSS到单独文件
  new MiniCssExtractPlugin()
]
```



#### devServer

作用：配置开发服务器行为

```javascript
devServer: {
  hot: true,                  // 启用热更新
  port: 3000,                 // 指定端口
  open: true,                 // 自动打开浏览器
  proxy: {                    // 代理API
    '/api': 'http://localhost:5000'   //用于解决跨域问题
  },
  static: './public'          // 静态文件目录
}
```



#### resolve

作用：控制模块文件名解析规则

```javascript
resolve: {
  extensions: ['.js', '.vue', '.json'], // 自动补全扩展名
  alias: {
    '@': path.resolve(__dirname, 'src') // 路径别名
  }
}
```



#### performance

作用：性能提示

```javascript
performance: {
  hints: 'warning',          // 'error'|'warning'|false
  maxAssetSize: 500000,      // 文件大小阈值（字节）
  maxEntrypointSize: 500000
}
```



## 二、Vite

### 启动过程

1. 命令解析

   1. 查找json文件scripts命令，实际执行vite serve命令

2. 启动开发服务器

   1. 创建Koa开发服务器
   2. 初始化文件监听器
   3. 建立WebSocket 用于热更新

3. 请求处理阶段

   1. 请求index.html，浏览器解析到`<script type="module">`发起模块请求

      ```html
      <!DOCTYPE html>
      <html>
        <head>
          <!-- 自动注入开发环境脚本 -->
          <script type="module" src="/@vite/client"></script>
        </head>
        <body>
          <div id="app"></div>
          <!-- 原生ESM方式引入入口文件 -->
          <script type="module" src="/src/main.js"></script>
        </body>
      </html>
      ```

4. 模块处理阶段

   1. Vite服务器拦截main.js请求并按需编译
      1. 对vue 和 js文件进行编译转换，其中`非原生ESM如CommonJS使用rollup进行快速编译`
      2. 转换结果返回浏览器

5. 热更新阶段

   1. 文件修改，Vite通过WebSocket推送更新消息，浏览器只请求修改的模块

6. Vue初始化并挂载到#app节点，页面渲染



### 常用配置

#### root

作用：确定项目根目录

#### server

作用：服务器配置

#### build

作用：构建配置

#### plugins

作用：插件配置

#### resolve

作用：解析配置

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  // 基础配置
  root: process.cwd(),          // 项目根目录
  base: '/',                    // 基础公共路径
  mode: 'development',          // 模式 development|production
  publicDir: 'public',          // 静态资源目录
  
  // 服务器配置
  server: {
    port: 3000,                 // 端口号
    open: true,                 // 自动打开浏览器
    cors: true,                 // 启用CORS
    proxy: {                    // 代理配置
      '/api': {
        target: 'http://localhost:5000',
        changeOrigin: true
      }
    }
  },
  
  // 构建配置
  build: {
    outDir: 'dist',             // 输出目录
    assetsDir: 'assets',        // 静态资源目录
    sourcemap: true,            // 是否生成sourcemap
    minify: 'esbuild'           // 压缩工具 esbuild|terser
  },
  
  // 插件配置
  plugins: [vue()],
  
  // 解析配置
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src') // 路径别名
    }
  }
})
```



## 三、Webpack & Vite 关键差异

| 特性                 | Vite               | Webpack     |
| :------------------- | :----------------- | :---------- |
| **开发启动原理**     | 原生ESM按需编译    | 全量打包    |
| **热更新速度**       | 直接替换修改的模块 | 重建依赖图  |
| **生产打包工具**     | Rollup             | Webpack自身 |
| **对现代ES特性支持** | 原生支持           | 需Babel转换 |
