# 机器学习 

> 机器学习的概念是指利用计算机算法和统计模型来使计算机系统具有学习能力的一门学科。

## 一、常见机器学习方法

1. **监督学习（Supervised Learning）：** 通过给定标记的训练数据来训练模型，使其能够预测新数据的标记或值。
2. **无监督学习（Unsupervised Learning）：** 使用未标记的数据来训练模型，发现数据之间的隐藏结构和模式。
3. **半监督学习（Semi-supervised Learning）：** 同时使用标记和未标记的数据来训练模型，通常用于数据量较大但标记数据较少的情况。
4. **强化学习（Reinforcement Learning）：** 通过与环境的交互来学习决策策略，以最大化累积奖励。
5. **深度学习（Deep Learning）：** 一种基于人工神经网络的机器学习方法，用于处理大规模的高维数据，并在诸如图像识别、语音识别和自然语言处理等领域取得了显著的成果
