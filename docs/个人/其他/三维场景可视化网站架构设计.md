# 三维场景可视化网站架构设计

## 一、系统整体选取

- 前端模板及人员分配
  - 框架选取（建议自适应框架，跨平台方便调整）
    - VUE
    - React
    - Angular
    - …
  - 页面布局(需要考虑不同平台实际展示的内容，因为数据量（尤其是三维模型）会非常大，所以不同平台展示的内容应该会有所不同)
    - 是否多端适配（PC、移动、平板）
    - Flex
    - Bootstrap
  - 预处理及样式库
    - Less/Sass
    - Element-UI
    - ant-desi gn-vue
    - Naïve
    - …
  - 功能模拟
    - Cesium1.96.0
    - Openlayers、MapBox、Leaflet？
    - … 请指明具体依赖的版本号
- 后端模板及人员分配（如JEECG平台）
  - SpringBoot 接口设计
    - 不同场景会有多源异构的数据，针对不同数据设计不同接口
    - Swagger接口文档
  - 数据库
    - 非空间数据存储（MySql、Redis）
      - 用户数据
      - 网站日志
      - …
    - 空间数据格式及存储
      - 数据来源
        - 二维及底图
          - 全国地理信息资源目录
          - OpenStreetMap
          - 天地图
          - …
        - 三维
          - Plateau
          - 东方道迩、亚洲航测
          - …
      - 格式
        - geojson
        - 3dTiles（fbx、obj、clm）
        - Osgb（转换方式）
        - Rvt（转换方式）
        - …
      - 存储
        - PostSQL
        - Sqlite
        - …
      - 其他（TOMCAT、IIS、GeoServer）
  - 服务器部署
    - 系统整体部署及测试
    - 服务器配置



## 二、灾种场景集成

- 现有模拟成果有多少，数据及模拟方式交流
  - 不同灾种有哪些同学共同开发，如何集成
  - 模型量是否会过大，造成流畅加载等问题
  - 是否根据上述系统设定，定个模板（如开发框架，可视化依赖库和数据库等）
  - …
- 场景交互方式
  - 针对不同灾害场景有何具体的要求，比如交互方式、渲染效果等
  - …
