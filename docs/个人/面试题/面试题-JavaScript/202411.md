### 1、Promise 并发控制

```javascript
function myLimitPromiseArr(promiseArr, limitNumber){
    let runningSize = 0
    let finishedSize = 0
    //task是一个二维数组，每个里面都有一个promise 和 一个index索引
    const taskQueue = Array.from({length: promiseArr.length}, ( _ , index) => [
        promiseArr[index],
        index
    ])
    const res = new Array(promiseArr.length)
    return new Promise((resolve, reject) => {
        const handle = function(){
            if(finishedSize === promiseArr.length) {
                resolve(res)
            }
            if(runningSize >= limitNumber || taskQueue.length === 0) return 
            const [task , index] = taskQueue.shift()
            task().then(
                val => {
                    res[index] = val
                },
                err => {
                    res[index] = err
                }
            ).finally(() => {
                runningSize--
                finishedSize++
                handle()
                console.log(res[index])
            })
            runningSize++
        }
        
        for(let i = 0; i < promiseArr.length; i++){
            handle()
        }
    })
}
```

### 2、ES6新特性

#### 1.**块级作用域**

let const创建的作用域，只在对应的区域生效

```javascript

{
    let x = 10;
    const y = 20;
    console.log(x); // 10
    console.log(y); // 20
}
console.log(x); // ReferenceError
console.log(y); // ReferenceError
```



#### 2.**箭头函数**

更便捷的方法书写方式

```javascript
const add = (a, b) => a + b;
console.log(add(5, 3)); // 8
```



#### 3.**模板字符串**

更方便的字符操作方式

```javascript
const name = 'World';
console.log(`Hello, ${name}!`); // Hello, World!
```



#### 4.**解构赋值**

可从数组 和 对象中提取值

```javascript

const arr = [1, 2, 3];
const [a, b] = arr;
console.log(a, b); // 1 2

const obj = { x: 1, y: 2 };
const { x, y } = obj;
console.log(x, y); // 1 2
```



#### 5.**类与继承**

引入类的概念，方便继承

```javascript
class Animal {
    constructor(name) {
        this.name = name
    } 
    getName() {
        return this.name
    }
}
class Dog extends Animal {
    constructor(name, age) {
        super(name)
        this.age = age
    }
}
```



#### 6.**模块化**

支持import 和 export方式管理代码

```javascript

// math.js
export const pi = 3.14;
export function add(x, y) {
    return x + y;
}

// main.js
import { pi, add } from './math.js';
console.log(pi); // 3.14
console.log(add(2, 3)); // 5
```



#### 7.**Promise**

处理异步操作的新机制，提供了更优雅的回调管理

```javascript

const fetchData = () => {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve('Data fetched');
        }, 1000);
    });
};

fetchData().then(data => console.log(data)); // Data fetched
```



### 3、可迭代对象

:bulb: 迭代协议：可迭代协议 和 迭代器协议

:bulb: 成为可迭代对象

- 该对象(或原型链上)实现 `[Symbol.iterator]()`方法
  - `可迭代协议`，要求键名为Symbol.iterator，涉及到Symbol的静态属性
    - 为每一个对象定义了默认的迭代器。该迭代器可以被 [`for...of`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Statements/for...of) 循环使用。
  - `迭代器协议`，键值为一个方法，该方法的返回值为符合迭代器协议的对象
    - 该对象要求实现next()方法，该next()方法返回符合Iterator接口的对象

#### 常见的可迭代对象

数组

```javascript
const arr = [1, 2, 3];
for (const item of arr) {
    console.log(item); // 输出 1, 2, 3
}

```

字符串

```javascript
const str = "abc";
for (const char of str) {
    console.log(char); // 输出 'a', 'b', 'c'
}

```

集合

```javascript
const set = new Set([1, 2, 3]);
for (const item of set) {
    console.log(item); // 输出 1, 2, 3
}

```

哈希表

```javascript
const map = new Map([['a', 1], ['b', 2]]);
for (const [key, value] of map) {
    console.log(key, value); // 输出 'a' 1 和 'b' 2
}

```

生成器

```javascript
function* gen() {
    yield 1;
    yield 2;
}
for (const value of gen()) {
    console.log(value); // 输出 1, 2
}
```
