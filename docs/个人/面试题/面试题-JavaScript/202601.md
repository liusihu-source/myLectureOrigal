# JavaScript面试题

### 1、静态方法 实例方法 和 原型方法

```javascript
function Foo() {
  Foo.a = function(){
    console.log(1)
  }
  this.a = function(){
  	console.log(2)
  }
  
}
Foo.prototype.a = function(){
	console.log(3)
}
Foo.a = function(){
	console.log(4)
}
Foo.a();  //4
let obj = new Foo();
obj.a();  /2
Foo.a();  //1
```

1. **定义构造函数 `Foo`**：

   一个构造函数，内部定义了两个方法：

   - 静态方法 `Foo.a`（执行时会覆盖之前的定义）
   - 实例方法 `this.a`

2. **扩展原型方法**：

   - 在 `Foo.prototype` 上添加方法 `a`，输出 `3`

3. **覆盖静态方法**：

   - 直接在 `Foo` 上定义静态方法 `a`，输出 `4`

4. **执行 `Foo.a()`**：

   - 调用当前 `Foo` 的静态方法 `a`，输出 `4`     //-------------------------首先输出4

5. **实例化对象 `obj`**：

   - ```
     let obj = new Foo()
     ```

     - 覆盖静态方法 `Foo.a` 为输出 `1` 的函数
     - 给实例添加方法 `a`，输出 `2`

     - 实例 `obj` 的 `a` 方法覆盖了原型链上的 `a` 方法

6. **执行 `obj.a()`**：

   - 调用实例 `obj` 的 `a` 方法，输出 `2`（优先调用实例自身方法） //-------------------------再输出2

7. **再次执行 `Foo.a()`**：

   - 此时静态方法 `Foo.a` 已被构造函数内部覆盖，输出 `1`   //-------------------------最后输出1
