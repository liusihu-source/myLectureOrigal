# HTML面试题

## 1、src 和 href区别

src是资源加载方式，herf是超链接引用

src

- src标签：script img audio video iframe等
- 加载方式
  - script脚本 同步阻塞，`async加载立即执行 或 defer页面解析后执行`
    - async 适合独立的脚本，如广告的加载
    - defer 依赖DOM的JS，保证脚本的执行顺序
  - img audio等异步非阻塞

href

- href标签：a link
- 加载方式
  - 异步非阻塞



优化

1. 图片`loading='lazy'`，延迟不在视口内的图片
2. CDN优化
3. 资源压缩

```html
<!DOCTYPE html>
```



## 4、meta标签

由name 和 content组成，用于描述网页文档的属性

- name--信息类型、名称
- content--信息值，文本等

```html
<meta name="description" content="这是一个页面描述。">
<meta name="keywords" content="关键词1, 关键词2">
<meta name="author" content="作者名">
```

## 6、img的srcset

为img标签指定多个图像源，根据屏幕大小和分辨率选择合适的图像

:bulb: 使用@media媒体查询可替换 

```html
<img 
  src="small.jpg"
  srcset="small.jpg 500w, 
  medium.jpg 1000w, 
  large.jpg 1500w"
  sizes="(max-width: 600px) 500px, (max-width: 900px) 1000px, 1500px"
  alt="示例图像"
>
```



## 7、title 和 h1

title - 制定标签页上的文本信息

h1 - 页面内最大标题

title更影响`搜索引擎结果页如何展示网页`，而h1影响`搜索引擎对页面的理解`



## 8、canvas 和 svg

用于网页图形绘制，Canvas基于像素的即时绘制技术，SVG基于矢量的图形格式

SVG

- 图标、图表、可缩放图形

Canvas

- 游戏开发、复杂动画
