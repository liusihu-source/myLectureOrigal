-  Vue DevTools 中识别组件，增强调试体验

- 在递归组件调用中，确保 Vue能够正确引用自身

  - ```javascript
    const Tree name：'Tree'，
    //其他选项
        template：
            <ul>
                <li v-for="node in treeData"：key="node.id">
                    {{node.name}}
                    <Tree v-if="node.children"：treeData="node.children"/>
                </li>
    		</ul>
        props：['treeData']
    }；
    ```

    

- 用于全局组件注册，使得组件能够被全局识别和使用

  - ```javascript
    import MyComponent from './MyComponent. vue'
    ```

- 提高在`<keep-alive>`中使用时的可读性和可调试性



### 2、Vue中data为何是函数，而不是对象

确保每个组件实例都有一个独立的状态

- 单页应用中使用多个Vue组件时，如果data是一个对象而不是函数，那么这些组件将共享同一个数据对象
- 将data定义为函数，在每次创建新组件实例时返回全新的对象，保证每个组件实例的数据都是独立的。



### 3、Vue中template标签作用

- vue2中，占位符 或者 插槽使用，最终在渲染的页面中template不会存在
- vue3中，同Vue2；当template 不与 指令共同使用，会被渲染为原生的template标签



### 4、Vue中设置404页面

在router文件中，`最后设置*的路由文件`

```javascript
import Vue from 'vue';
import VueRouter from 'vue-router';

Vue.use(VueRouter);

const routes = [
  {
    path: '/',
    component: () => import('/src/components/Home.vue')
  },
  {
    path: '*', // 通配符，一定要放在最后
    component: () => import('@/components/NotFound.vue')
  }
];

const router = new VueRouter({
  mode: 'history', // 使用 HTML5 History 模式
  routes
});

export default router;
```



### 5、vue-router传递 和 获取参数

方式一 路径参数this.$route.params

在index.js路由文件定义路径参数 `动态路径`

```javascript
const routes = [
  {
    path: '/user/:id',
    name: 'User',
    component: UserComponent
  }
];

```

router.push()中添加路径参数

```javascript
this.$router.push({ name: 'User', params: { id: 123 } });
```

获取参数

```vue
export default {
  mounted() {
    console.log(this.$route.params.id); // 输出: 123
  }
}

```



方式二 查询参数  this.$route.query

router.push()传递路由参数

```javascript
this.$router.push({ path: '/user', query: { id: 123, name: 'John' } });
```

获取参数

```vue
export default {
  mounted() {
    console.log(this.$route.query.id);    // 输出: 123
    console.log(this.$route.query.name);  // 输出: John
  }
}

```



### 6、Diff算法

`比较新旧虚拟DOM树的`的算法，主要目的是最小化成本更新DOM

- 虚拟DOM树
  - 内存中操作的javaScript对象，避免频繁操作真实DOM
- 具体做法
  - 从根节点递归比较新旧DOM树，深度优先遍历
    - 同层级节点类型不同，直接替换
    - 类型相同，递归检查子节点

:bulb: 在更新过程中，给每个优化列表添加唯一Key，方便快速定位



### 7、vuex数据监听

> watch用于对state值变化的监听，subscribe用于对mutation的监听

#### watch

```javascript
export default {
  name: 'parent',
  data() {
    return {
      msg: 'hello!',
      obj1: {
          user: '小虎'
      }
    }
  },
  methods: {
  },
  watch: {
      msg: function (newVal, oldVal) {
          console.log(newVal, oldVal)
      },
      obj1: {
          handler: function(newVal, oldVal) {
            console.log(newVal, oldVal)
        },
        deep: true  //深度监听，用于当监听变量是一个对象时候使用
      },
      '$router.path'(newVal, oldVal) {
          console.log(newVal, oldVal)  //可用于监听路由
      },
      '$store.state.data.age'(newVal,oldVal){
          //对数据执行操作
          console.log(newVal,oldVal)
      }
  }
}
</script>
```



#### subscribe

```javascript
//store.js文件mutations方法被调用
const mutations = {
  UPDATE_USER(state, user) {
    state.user = user;
  },
};

store.commit('UPDATE_USER', { name: 'Alice', age: 25 });
```

在`store实例注册回调函数subscribe`，用于`监听Mutation`，组件使用如下

```javascript
this.$store.subscribe((mutation, state) => {
  console.log('Mutation Type:', mutation.type);
  console.log('Mutation Payload:', mutation.payload);
});

//Mutation Type: UPDATE_USER
//Mutation Payload: { name: 'Alice', age: 25 }

```



### 8、defineAsyncComponent

异步加载组件，页面需要再加载组件。

```javascript
import { defineAsyncComponent } from 'vue';

const AsyncComponent = defineAsyncComponent(() =>
  import('./components/YourComponent.vue')
);

export default {
  components: {
    AsyncComponent
  }
};

```
