# Vue面试题

## 1、vue-router 的哈希模式和历史模式

### 哈希模式

:bulb: #后的内容被视为网页的内容，是一个锚点，不会发送到服务器。

1. 当页面#后内容修改，会触发window.hashchange事件
2. vue-router监听hashchange事件，然后内部会解析`window.location.hash`的值，然后匹配该值与router值中具体的组件，最后将对应组件更新到`<routerView>`标签中



### 历史模式

:bulb: 主要监听popstate事件

1. 当用户点击前进或后退按钮时，会触发popstate事件，vue-router监听该事件
2. 内部重写pushstate 和 replacestate事件，并解析`window.location.pathname`值，最后同上匹配组件并更新到`<routerView>`标签中



## 2、完整vue组件

```vue
<template>
	<div>首页</div>
  <p> 当前计数：{{count}}</p>
  <button @click='increment'>加1</button>
</template>

<script setup>
	import {refs, onMounted} from 'vue';
  const count = ref(0)
  onMounted(() => {
    console.log('初始化')
  })
  function increment(){
    count.value += 1
  }
</script>

<style lang='scss' scoped>
/*样式*/
</style>
```
