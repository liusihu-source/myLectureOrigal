# CSS面试题

## 1、css优先级

- 内联
- ID
- 类
- 元素和伪元素
- 通配符

计算权重值：`内联1000、ID100、类/属性/伪类10、元素选择器1`



## 2、继承 和 不可继承属性

可继承：如color、font-family、text-align等

不可继承：如background、border、margin等

:bulb: 使用inherit明确某个属性继承父元素值

```css
.child {
    color: inherit; // 强制继承父元素的文字颜色
}
```



## 3、link 和 @import引用CSS

link：在html文档的`<head>`部分，随页面并行加载

@import：在css文件 或 `<style>`标签中，顺序加载速度慢
